01 · Core Standard & Kernel

AgDR + Atomic Kernel Inference

AgDR v0.2 / v1.8

Atomic Genesis Decision Record — the open Canadian evidentiary standard. Every autonomous decision is cryptographically bound to its context at the exact instant of inference.

AKI Formal Invariant

AKI(i) = { commit(AgDR(PPP, Trace, Delta)) ⇔ output(Result) }. No sealed commitment → no output. Enforced at the kernel boundary, not as a logging side-effect.

PPP Triplet

Provenance · Place · Purpose. Mathematically indivisible. Failure of any pillar aborts the inference atomically. Satisfies Canada Evidence Act authentication requirements by construction.

HumanDeltaChain

Human-in-the-loop escalation protocol that records the chain of accountable human authority alongside every machine decision.

02 · Cryptographic Substrate

Sealing, Chains & Proofs

  • HASH
    BLAKE3 — primary cryptographic hash for chain integrity and commitments.
  • SIG
    Ed25519 (with post-quantum path via Mantle) — non-repudiable sealing at the inference instant.
  • TREE
    Forward-secret Merkle / JellyfishSMT — persistent, verifiable append-only sensory spine.
  • ZK
    NANOZK-style hooks — zero-knowledge verification paths for court-admissible computation claims.
  • ATOMIC
    Kernel critical section — true atomic capture (no clocks, interrupt-safe) so the record cannot be decoupled from the decision.

Sovereign post-quantum fortification layer. Three-tier lineage (Core → Implementation → Fortification). Python package agdr-mantle.

Provenance Packet work (protobuf). Minimal immutable provenance primitive intended for zero-latency, zero-packet-loss global agent communication; PPP-enforced; FEC 4+1 XOR. The component referred to when speaking of a transport-layer replacement for agentic traffic.

04 · Actuarial Layer

Actuarial Safe Harbor Protocol (ASHP)

Monograph AAI-ACT-2026-V10.0. Converts unbounded stochastic AI tail risk into a capped, parameterizable, fully insurable risk layer.

Dual-Capped Truncation

Statutory ceilings on economic and non-economic damages that render expected loss and variance finite for reserving.

Bühlmann-Straub Credibility

Dynamic capital discounts that grow only with verified zero-knowledge telemetry experience (ASOP No. 25).

Upstream Model Warranty (UFMW)

Bankruptcy-remote collateralized warranties so downstream entities can treat foundation-model risk as a recoverable.

Velocity-Indexed Time-at-Risk

Capital charges scaled by actual remediation window rather than policy year — critical for high-frequency agents.

Parametric Systemic Triggers

Three-tier architecture isolating idiosyncratic loss, foundation-model contagion, and demographic-parity failures.

Model Legislative Text

Ready-to-adapt statutory language creating a rebuttable affirmative defense for compliant systems.
